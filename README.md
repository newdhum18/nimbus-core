# Nimbus Core

Private cloud search platform starter.

This repository is the external alias for **Mega Hunter Pro Monitor**.

## Version
0.2.0 Flat Starter

## Purpose
This version is intentionally flat so it can be uploaded from iPhone GitHub without folders.

## Current features
- PWA-ready dashboard
- Temporary local PIN screen
- Latest discoveries UI
- Protected sources UI
- Archive UI
- Search Now placeholder
- Local demo data

## Next phase
V3 will add Cloudflare Pages Functions, Brave Search API, and Cloudflare D1 database.
