Version: 27-sourceboost.4-wide1000

Important correction made during verification:
- The uploaded wide1000 build had a newline decoding bug in decodeLoose(): it joined decoded variants using a literal backslash-n string instead of a real newline.
- This caused some fully URL-encoded MEGA links to be missed.
- Fixed in this package by changing join('\\n') to join('\n').

Practical limits:
- The app contains 1000 source templates.
- A single Cloudflare Worker request should not fetch all 1000 sources at once because of Cloudflare time limits.
- The aggressive per-request hard cap remains 240 source fetches and 200 deep rounds.
- For stable production use, start with MAX_SOURCE_FETCHES=120 and DEEP_ROUNDS=160, then raise gradually.
